4. Teclado (E02)

Esta aplicación enseña como introducir los controles del teclado en el programa para la iteración de la persona con la aplicación.

Esta función permite modificar las propiedades de color RGB en la función glColor3f() anteriormente explicada. Para visualizar mejor esta propiedad se le aumenta el grosor a la línea. La forma de realizarlo es usando las teclas 'r', 'g' y 'b', que en minúsculas disminuyen la propiedad 'roja' la 'r', 'verde' la 'g' y 'azul' la 'b', y en mayúsculas la aumentan. De esta forma se enseña también la propiedad mencionada y se acerca a comprender la importancia de estos colores. También se usa la tecla que finaliza la aplicación.

Funciones añadidas en esta aplicación:

  • glLineWidth(10.0) - Selecciona el ancho de las líneas dibujadas con GL_LINES.

  • glutKeyboardFunc(Teclado) - Cuando se pulsa una tecla el sistema llamara automáticamente a la función Teclado, creada por el programador.

  • void Teclado (unsigned char key, int x, int y) - Esta función es llamada cada vez que el usuario pulsa una tecla. La función modifica el valor de tres variables globales, que serán las utilizadas en la llamada a la función glColor3f.

  • glutPostRedisplay() - Manda repintar la ventana, es decir, el sistema indica que se ha de ejecutar la función definida en glutDisplayFunc().

Otras funciones relacionadas con la iteración son:

  • glutMouseFunc(void (*func)(int button, int state, int x, int y)) - Llama a la función definida, cuando se pulsa (o suelta) algún botón del ratón dentro de la ventana de OpenGL. Los parámetros que se pasan a la función son el botón pulsado (GLUT_LEFT_BUTTON izquierdo, GLUT_RIGHT_BUTTON derecho y GLUT_MIDDLE_BUTTON central), la acción (GLUT_DOWN pulsar o GLUT_UP soltar), y las coordenadas donde esta el puntero en relación a la esquina superior izquierda de la ventana de renderizado.

  • glutMotionFunc(void (*func)(int x, int y)) - Llama a la función definida cada cierto tiempo si el ratón esta activo, tiene algún botón pulsado. Los parámetros que le pasa a la función son las coordenadas del puntero.

  • glutPassiveMotionFunc(void (*func)(int x, int y)) - Llama a la función definida cada cierto tiempo si el ratón esta pasivo, no tiene ningún botón pulsado. Los parámetros que le pasa a la función son las coordenadas del puntero.

     

Código fuente

E02.c

// ejemplo que dibuja una simple linea 
// y el usuario puede cambiar el color
// pulsando las teclas 'r' 'g' 'b'
// en minusculas decrementa
// en mayusculas incrementa
#include < GL/glut.h >
#include < stdio.h >

#define WIDTH  200		/* Ancho ventanas en pixels */
#define HEIGHT 200		/* Alto ventanas en pixels */

GLfloat FEA_Red   = 0.0f;
GLfloat FEA_Green = 0.0f;
GLfloat FEA_Blue  = 0.0f;

void Display(void)
{	
glClear( GL_COLOR_BUFFER_BIT );
glColor3f( FEA_Red, FEA_Green, FEA_Blue );
	glLineWidth(10.0f);

	glBegin( GL_LINES );
		glVertex3f( -30.0f, -30.0f, 0.0f );
		glVertex3f( 30.0f, 30.0f, 0.0f );
	glEnd();

	glFlush();
}

// control del teclado
void Teclado (unsigned char key, int x, int y)
{
	switch(key)
	{
	case 'r': 
		if (FEA_Red > 0.01) FEA_Red = FEA_Red - 0.1;
		printf (" * rojo  (R) = %f \n",FEA_Red);
		printf ("   verde (G) = %f \n",FEA_Green);
		printf ("   azul  (B) = %f \n",FEA_Blue);
		printf (" \n *********** \n");
		break;
	case 'R':
		if (FEA_Red < 1.0) FEA_Red = FEA_Red + 0.1;
		printf (" * rojo  (R) = %f \n",FEA_Red);
		printf ("   verde (G) = %f \n",FEA_Green);
		printf ("   azul  (B) = %f \n",FEA_Blue);
		printf (" \n *********** \n");
		break;
	case 'b': 
		if (FEA_Blue > 0.01) FEA_Blue = FEA_Blue - 0.1;
		printf ("   rojo  (R) = %f \n",FEA_Red);
		printf ("   verde (G) = %f \n",FEA_Green);
		printf (" * azul  (B) = %f \n",FEA_Blue);
		printf (" \n *********** \n");
		break;
	case 'B':
		if (FEA_Blue < 1.0) FEA_Blue = FEA_Blue + 0.1;
		printf ("   rojo  (R) = %f \n",FEA_Red);
		printf ("   verde (G) = %f \n",FEA_Green);
		printf (" * azul  (B) = %f \n",FEA_Blue);
		printf (" \n *********** \n");
		break;
	case 'g': 
		if (FEA_Green > 0.01) FEA_Green = FEA_Green - 0.1;
		printf ("   rojo  (R) = %f \n",FEA_Red);
		printf (" * verde (G) = %f \n",FEA_Green);
		printf ("   azul  (B) = %f \n",FEA_Blue);
		printf (" \n *********** \n");
		break;
	case 'G':
		if (FEA_Green < 1.0) FEA_Green = FEA_Green + 0.1;
		printf ("   rojo  (R) = %f \n",FEA_Red);
		printf (" * verde (G) = %f \n",FEA_Green);
		printf ("   azul  (B) = %f \n",FEA_Blue);
		printf (" \n *********** \n");
		break;
	case 27:  // 
		exit(0);
		break;
	}
	glutPostRedisplay();
}

void Resize( int w, int h )
{
	glClearColor( 1.0, 1.0, 1.0, 1.0 );

	glViewport( 0, 0, w, h );

	glMatrixMode(GL_PROJECTION);
	glLoadIdentity();
	// creamos un volumen de visualizacion
	glOrtho( -50.0, 50.0, -50.0, 50.0, -50.0, 50.0 );

	glMatrixMode(GL_MODELVIEW);
	glLoadIdentity();
}

int main(int argc, char** argv)
{
	glutInitDisplayMode ( GLUT_RGB );
	glutInitWindowSize ( WIDTH, HEIGHT );
	glutInitWindowPosition ( 100, 100 );
	glutCreateWindow("E02: Teclado");
	glutDisplayFunc(Display);
	glutKeyboardFunc(Teclado);
	glutReshapeFunc( Resize );
	glutMainLoop();	return 0;   
}
