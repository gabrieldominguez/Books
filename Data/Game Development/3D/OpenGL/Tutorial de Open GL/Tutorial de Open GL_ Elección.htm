10. Elección (E08)

Esta función explica los pasos a realizar para que el usuario pueda seleccionar objetos de la pantalla.

Con las propiedades de selección se puede definir un volumen y determinar que objetos se encuentran en el. De esta forma elegir entre estos objetos y modificarlos o moverlos.
Para ello el ejemplo lo que hace es generar el juego del tres en raya (tick tack tres). El usuario selecciona una pieza y luego la casilla a la que la quiere mover. Para realizar estas selecciones primero es necesario especificar un buffer de selección en el cual en lugar de dibujar la escena se localizan los objetos que se dibujarían en ese punto de la escena. Para poder saber que objetos se deberían dibujar en ese punto es necesario especificar que es lo que se dibuja en ese momento.

Las instrucciones utilizadas para realizar todo esto son:

  • glLoadName(GREEN1) - Introduce en la pila de nombres, cambiando el actual por el que identificará a las figuras a dibujar mientras no se especifique otro.

  • void ProcessPick( GLuint *selectBuff) - Función que procesa la información que se encuentra en el buffer de selección.

  • void ProcessSelection ( int x, int y ) - Función que procesa las coordenadas del ratón en el momento que se pulsa, y que genera el buffer de selección, así como la localización de los objetos que se encuentran en ese momento en las coordenadas del ratón. Es creada por el programador y en ella se encuentran las siguientes funciones:

    • glSelectBuffer(64, selectBuff) - Selecciona el buffer donde se crearan los puntos de referencia, en lugar de ser pintados en pantalla. Se indica el numero de valores que se pueden escribir y un puntero a memoria donde comienza a guardarse la información.
      El buffer de selección tiene el siguiente formato: 

      Buffer de selección                   [0]      Numero de identificadores en la pila con un
                                                      tiempo t=n0 
                                            [1]      Mínimo valor de Z 
                                            [2]      Máximo valor de Z 
                                            [n0+2] Fin pila de identificadores 
                                             ... 
Siguiente punto de referencia -> [n0+3] Numero de identificadores en la pila 
                                                      para el registro n1 
                                            [n0+4] Mínimo valor de Z
      Figura 3.1 - Formato de almacenamiento del buffer de selección

     

    • glRenderMode(GL_SELECT) - Activa el modo de generación. Este puede ser GL_RENDER, por defecto, las operaciones de dibujo colocan los pixels en el buffer de cuadro (dibujo), GL_SELECT, no se modifica el buffer de cuadro, en su lugar se escriben puntos de referencia en el buffer de selección, GL_FEEDBACK, modo de reglamentación. Esta función devuelve un valor que depende del modo de generación. En el caso de GL_SELECT es el numero de puntos de referencia escritos en el buffer de selección.

    • gluPickMatrix(x, (HEIGHT-y), 2,2,viewport) - Especifica la zona de selección. Indica también la precisión de ésta, en este caso dos pixels de ancho y de alto. Sobre la posición del ratón explicar que OpenGL ordena la coordenada Y de abajo a arriba, y Windows al contrario, por lo tanto hay que convertir la coordenada Y, restándosela al alto de la ventana.

    • glInitNames() - Inicializa la pila de nombres.

    • glPushName(0) - Introduce un cero en la pila de nombres.

void Display( void )
{
	int      j = 1;
	GLint    viewport[4];


	glClear( GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT );	
	
	glGetIntegerv( GL_VIEWPORT, viewport ); 

	glMatrixMode( GL_PROJECTION );
	glLoadIdentity();

	gluPerspective(60.0, viewport[2]/viewport[3],
		           0.0, 100.0);  

	glMatrixMode( GL_MODELVIEW );
	glLoadIdentity();

	glPushMatrix(); 

	gluLookAt( FEA_eyeX,    FEA_eyeY,		FEA_eyeZ,
	           FEA_centerX, FEA_centerY,	FEA_centerZ,
			   0.0f,		1.0f,			0.0f);

	glPopMatrix();
	glutSwapBuffers();
}

void Light ()
{	

	GLfloat DiffuseLight[4] = { 0.8f, 0.8f, 0.8f, 1.0f };
	GLfloat AmbientLight[4] = { 0.3f, 0.3f, 0.3f, 1.0f };
	GLfloat SpecularLight[4] = { 1.0f, 1.0f, 1.0f, 1.0f };
	GLfloat LightPos[4] = {0.0f, 10.0f, 10.0f, 1.0f };


	glDepthFunc( GL_LESS); 
	glClearDepth(1.0);
	glEnable( GL_DEPTH_TEST );


	glCullFace (GL_BACK);
	glFrontFace (GL_CW);
	glEnable( GL_CULL_FACE );

	// definimos las luces
	glEnable( GL_LIGHTING );


	glLightfv( GL_LIGHT0, GL_AMBIENT, AmbientLight );
	glLightfv( GL_LIGHT0, GL_DIFFUSE, DiffuseLight );
	glLightfv( GL_LIGHT0, GL_SPECULAR, SpecularLight );
	glLightfv( GL_LIGHT0, GL_POSITION, LightPos );
	glEnable( GL_LIGHT0 );


	glEnable (GL_COLOR_MATERIAL );

	glColorMaterial (GL_FRONT,GL_AMBIENT_AND_DIFFUSE );

	glMaterialfv (GL_FRONT, GL_SPECULAR, SpecularLight);
	glMateriali (GL_FRONT, GL_SHININESS, 128);
	
	glEnable(GL_NORMALIZE);

}

void ProcessSelection ( int x, int y )
{

	// Espacio para el buffer de seleccion
	GLuint selectBuff[64];
	// control de entrada y almacenamiento de la vista
	GLint hits, viewport[4];

	// define el buffer
	glSelectBuffer(64, selectBuff);
	// coge la vista
	glGetIntegerv(GL_VIEWPORT, viewport);
	// cambia la proyeccion y la almacena
	glMatrixMode(GL_PROJECTION);
	glPushMatrix();

	// Cambia el modo a Seleccion
	glRenderMode(GL_SELECT);

	// Se establece un nuevo espacio de trabajo de na unidad cubica
	// alrededor de la posicion del raton  extendiendo dos pixels en 
	// vertical y horizontal, Es la precision de la seleccion.
	glLoadIdentity();
	gluPickMatrix(x, (HEIGHT-y), 2,2,viewport);

	// Dibuja la escena

	gluPerspective(60.0, viewport[2]/viewport[3],
		           0.0, 100.0);  
	gluLookAt( FEA_eyeX,    FEA_eyeY,		FEA_eyeZ,
	           FEA_centerX, FEA_centerY,	FEA_centerZ,
		     0.0f,		1.0f,			0.0f); 

	glInitNames();
	glPushName(0);

	DrawWordl();

	// recoge los puntos de referencia
	hits = glRenderMode( GL_RENDER);

	// Si tiene lugar una entrada actua
	if (hits >= 1) ProcessPick(selectBuff);

	// Recupera la matriz de proyeccion
	glMatrixMode ( GL_PROJECTION);
	glPopMatrix();

	// Vuelve al modelador
	glMatrixMode(GL_MODELVIEW);
}
