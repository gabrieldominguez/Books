NAME
     startgfx, stopgfx - start/stop the	window system

SYNOPSIS
     /usr/gfx/startgfx /usr/gfx/stopgfx

DESCRIPTION
     startgfx turns the	windowsystem configuration flag	on, and	executes the X
     Display Manager, xdm.  stopgfx turns the windowsystem configuration flag
     off, and terminates the X Display Manager.

SEE ALSO
     chkconfig(1m), xdm(1), gfxinfo(1g)
