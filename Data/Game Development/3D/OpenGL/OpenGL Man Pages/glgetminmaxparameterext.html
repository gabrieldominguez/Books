glGetMinmaxParameterEXT(3G)    OpenGL Reference	   glGetMinmaxParameterEXT(3G)



NAME
     glGetMinmaxParameterfvEXT,	glGetMinmaxParameterivEXT - get	minmax
     parameters


C SPECIFICATION
     void glGetMinmaxParameterfvEXT( GLenum target,
				     GLenum pname,
				     GLfloat *params )
     void glGetMinmaxParameterivEXT( GLenum target,
				     GLenum pname,
				     GLint *params )


PARAMETERS
     target  Must be GL_MINMAX_EXT.

     pname   The parameter to be retrieved.  Must be one of
	     GL_MINMAX_FORMAT_EXT or GL_MINMAX_SINK_EXT.

     params  A pointer to storage for the retrieved parameters.

DESCRIPTION
     glGetMinmaxParameterEXT retrieves parameters for the current minmax
     table.  See glMinmaxEXT for detailed descriptions of these	parameters.

ERRORS
     GL_INVALID_ENUM is	generated if target is not GL_MINMAX_EXT.

     GL_INVALID_ENUM is	generated if pname is not one of the allowable values.

     GL_INVALID_OPERATION is generated if glGetMinmaxParameterEXT is executed
     between the execution of glBegin and the corresponding execution of
     glEnd.


SEE ALSO
     glMinmaxEXT, glGetMinmaxEXT.
