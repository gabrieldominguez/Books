7. Cámara(E05)

Esta función introduce efectos de cámara.

Para la cámara es necesario definir 2 puntos, el ojo o posición desde donde se mira (eye), y el centro o punto de mira (center), aquel punto a donde se dirige la vista; un vector, que indica la inclinación, o "verticalidad" de la cabeza (up); y un ángulo, con el que se indica el ángulo de visión o zoom. También hay que definir dos distancias, para determinar el volumen de visualización, son el 'near' y el 'back'.

Las funciones que tiene la cámara son las siguientes:

  • CamCreate( Max, Min ) - Crea una cámara, con un volumen de visualización que abarca Max, Min, y reserva memoria.

  • CamMeridiam ( , ) - Rota la cámara alrededor de un eje paralelo al X de la cámara y que pasa por Center.

  • CamParalell ( , ) - Rota la cámara alrededor de un eje paralelo al Y del mundo y pasa por Center.

  • CamTilt ( , ) - Rota la cámara por su eje Z negativo.

  • CamZoom ( , ) - Realiza un zoom, acercamiento y/o alejamiento, al variar el ángulo de visión.

La interfaz utilizada es una ampliación al de E04, al que se le añaden las teclas F5 y F6. Con estas dos teclas se selecciona el tipo de acción a realizar posteriormente con los cursores. F5 activa las acciones Meridiam y Paralell, que se manejan con los cursores Up/Down para la acción Meridiam y Rigth/Left para la función Paralell, mientras que F6 activa las acciones Tilt y Zoom, con los cursores Up/Down para el Zoom y Rigth/Left para Tilt.

Funciones añadidas en esta aplicación:

  • gluLookAt( ojo, centro, inclinación) - Sitúa la cámara en el mundo. La cámara se sitúa en el punto referenciado por ojo, mirando a centro.

  • glPerspective( ángulo, relación, frontal, fondo ) - Esta función define el volumen de visualización para una vista en perspectiva cónica. Los parámetros son el ángulo en vertical, la relación entre la anchura y la altura, la distancia del objeto más cercano y la del más lejano.

Estas funciones están relacionadas con las funciones siguientes ya vistas en ejemplos anteriores, pero que no estaban explicadas:

  • glMatrixMode( ) - Esta función especifica la matriz actual, es decir determina que pila de matrices se utilizará en las operaciones de matrices. Esta matriz puede ser de los tipos GL_MODELVIEW, se emplea para mover objetos por la escena, afecta a la pila de matrices del Modelador, GL_PROJECTION, se emplea para definir el volumen de trabajo, afecta a la pila de matrices de la Proyección, y GL_TEXTURE, manipula las coordenadas de textura, que se verá en otro ejemplo más adelante.

  • glLoadIdentity() - Reemplaza la matriz actual por la matriz Identidad. Afecta a la pila de matrices indicada la última vez por glMatrixMode().

  • glOrtho( -50.0, 50.0, -50.0, 50.0, -50.0, 50.0 ) - Define el volumen de trabajo paralelo, perspectiva ortogonal. Los parámetros son en coordenadas cartesianas, la X mínima y máximo, Y mínimo y máximo, y Z mínimo y máximo.

    	FEA_minZ    = poly->zCoor[1];


	while ( j <= numPol )
	{ 
		for ( i=0; i < poly->numVert; i++ )
		{
			if ( FEA_maxX < poly->xCoor[i] ) 
FEA_maxX = poly->xCoor[i];
if ( FEA_minX > poly->xCoor[i] ) 
FEA_minX = poly->xCoor[i];

FEA_maxZ = poly->zCoor[i];

FEA_minZ = poly->zCoor[i];

	j++;
		poly=GetNext( FEA_ListPol );
	}
}

// con eye y center obtengo el vector de coordenadas  'n-'
// con eye y up obtengo el vector de coordenadas 'v+'
// el vector de coordenadas 'u+' se obtiene con los anteriores 

camera *CamCreate ( float maxX, float maxY, float maxZ,
				    float minX, float minY, float minZ)
{ // La camara se inicializa paralela al eje Xw. 
  // Englobando en su volumen de vision lo contenido dentro de los 
  // puntos dados con una inclinacion vertical. Y un angulo de 
  // apertura inicial de 60º
	
	float radio, distance;
	float alpha = 60;
	camera *newCamera;

	newCamera = (camera *) malloc( sizeof(camera) * 1);


	newCamera->centerX = (maxX + minX)/2;
	newCamera->centerY = (maxY + minY)/2;
	newCamera->centerZ = (maxZ + minZ)/2;

	radio = (sqrt(  pow(maxX-newCamera->centerX,2) 
	 	          + pow(maxY-newCamera->centerY,2)
		          + pow(maxZ-newCamera->centerZ,2)));


	distance = radio / tan ( DEGREE_TO_RAD * (alpha/2));  

	newCamera->eyeX = ((maxX + minX)/2) + distance*3/2;
	newCamera->eyeY = (maxY + minY)/2;
	newCamera->eyeZ = (maxZ + minZ)/2;

	newCamera->upX = 0.0;
	newCamera->upY = 1.0;
	newCamera->upZ = 0.0;

	newCamera->angle = alpha;

	newCamera->front  = distance * 3;
	newCamera->back = distance / 10;

	newCamera->initCenterX = newCamera->centerX;
	newCamera->initCenterY = newCamera->centerY;
	newCamera->initCenterZ = newCamera->centerZ;

	newCamera->initEyeX = newCamera->eyeX;
	newCamera->initEyeY = newCamera->eyeY;
	newCamera->initEyeZ = newCamera->eyeZ;

	newCamera->initUpX = newCamera->upX;
	newCamera->initUpY = newCamera->upY;
	newCamera->initUpZ = newCamera->upZ;

	newCamera->initAngle = newCamera->angle;
	newCamera->initFront = newCamera->front;
	newCamera->initBack  = newCamera->back;

	return newCamera;
}

void CamMeridiam ( camera *cam, float angle )
{// rotacion sobre el eje paralelo a Xw y que pasa por center

	trfm3D *matrix;     
	float  px, py, pz;  
	float  vx, vy, vz;
	float  cx, cy, cz;
	float  ex, ey, ez;
	float  ux, uy, uz;

	cx = cam->centerX;
	cy = cam->centerY;
	cz = cam->centerZ;

	ex = cam->eyeX;
	ey = cam->eyeY;
	ez = cam->eyeZ;

	ux = cam->upX;
	uy = cam->upY;
	uz = cam->upZ;

	// Calculamos el vector Center-Eye

	vx = cx-ex;
	vy = cy-ey;
	vz = cz-ez;

	// Calculamos el eje X de la camara, que es el producto 
// cartesiano entre v-u

	
	px = vy* uz - vz*uy;
	py = vz* ux - vx*uz;
	pz = vx* uy - vy*ux;

	// Con el vector que define el eje X, obtenemos el eje por sobre 
// el que debe girar la camara

	vx = cx+px;
	vy = cy+py;
	vz = cz+pz;


	matrix = SetAxisRot (	vx, vy, vz,
					cx, cy, cz,	
					angle );

	// localizamos el punto sobre el que se apoya la inclinacion de 
// la camara

	px = ex+ux;
	py = ey+uy;
	pz = ez+uz;

	// rotamos el ojo (eye)

	Transform3D ( matrix, &ex, &ey, &ez);

	cam->eyeX = ex;
	cam->eyeY = ey;
	cam->eyeZ = ez;

	// rotamos la inlinacion de la camara

	Transform3D( matrix, &px, &py, &pz );

	cam->upX = px - cam->eyeX;
	cam->upY = py - cam->eyeY;
	cam->upZ = pz - cam->eyeZ;

}


void CamParalell ( camera *cam, float angle )
{// rotacion sobre el eje paralelo al Yw y que pasa por center

	float ci, an, bn, alpha, cs;
	float cx, cz, ex, ez, ux, uz;

	cx = cam->centerX;
	cz = cam->centerZ;
	ex = cam->eyeX;
	ez = cam->eyeZ;
	ux = cam->upX+cam->eyeX;
	uz = cam->upZ+cam->eyeZ;

	if (ez < cz) angle = -angle; 

	ci = sqrt ( pow((cx-ex),2) + pow((cz-ez),2));

	if (ci != 0 ) // evita la division por cero
		cs = (ex-cx)/ci;
	else cs = 1.0;

	alpha = acos(cs);

	an = cos(alpha+(DEGREE_TO_RAD * angle))*ci;
	bn = sin(alpha+(DEGREE_TO_RAD * angle))*ci;

	cam- >eyeX = cx+an;

	if (ez < cz) cam- >eyeZ = cz-bn; 		
	else cam->eyeZ = cz+bn;

	// ahora relizamos la rotacion del punto donde se apoya la 
// inclinacion de la camara
	// para que esta no cambie, en relacion a la nueva posicion

	ci = sqrt ( pow((cx-ux),2) + pow((cz-uz),2));

	if (ci != 0 ) // evita la division por cero
		cs = (ux-cx)/ci;
	else cs = 1.0;

	alpha = acos(cs);

	an = cos(alpha+(DEGREE_TO_RAD * angle))*ci;
	bn = sin(alpha+(DEGREE_TO_RAD * angle))*ci;

	ux = cx+an;

	if (uz < cz) uz = cz-bn; 		
	else uz = cz+bn;

	cam- >upX = ux-cam->eyeX;
	cam->upZ = uz-cam->eyeZ;

}


void CamTilt ( camera *cam, float angle )
{// rotacion sobre el eje Zc

	trfm3D *matrix;
	float  px, py, pz;

	matrix = SetAxisRot ( cam-> eyeX,   cam->eyeY,    cam->eyeZ,
			          cam->centerX, cam->centerY, cam->centerZ,
			          angle );
	 
	px = cam->eyeX + cam->upX;
	py = cam->eyeY + cam->upY;
	pz = cam->eyeZ + cam->upZ;

	Transform3D( matrix, &px, &py, &pz );

	cam->upX = px - cam->eyeX;
	cam->upY = py - cam->eyeY;
	cam->upZ = pz - cam->eyeZ;

}


void CamZoom ( camera *cam, float angle)
{// modifica el angulo de vision
	cam->angle = cam->angle + angle;
}




void CamReset ( camera *cam )
{
	cam->centerX = cam->initCenterX;
	cam->centerY = cam->initCenterY;
	cam->centerZ = cam->initCenterZ;

	cam->eyeX    = cam->initEyeX;
	cam->eyeY    = cam->initEyeY;
	cam->eyeZ    = cam->initEyeZ;

	cam->upX     = cam->initUpX;
	cam->upY     = cam->initUpY;
	cam->upZ     = cam->initUpZ;

	cam->angle   = cam->initAngle;
	cam->front   = cam->initFront;
	cam->back    = cam->initBack;
}

/* Devuelve la matriz que permite rotar un punto alrededor de un eje arbitrario
   definido mediante los puntos que pasan los argumentos p1 y p2, un angulo 
   determinado expresado en grados*/
trfm3D *SetAxisRot ( float p1x, float p1y, float p1z,

trfm3D *SetAxisRot ( float p1x, float p1y, float p1z,
				  float p2x, float p2y, float p2z,
				  float angle )
{
	float  angRad, cosAng, sinAng, t;
	trfm3D *matrix1, *matrix2, *matrix3;
	float axisX, axisY, axisZ;
	float length;

	matrix1 = CreateTrfm3D();
	matrix2 = CreateTrfm3D();
	matrix3 = CreateTrfm3D();

	angRad = DEGREE_TO_RAD * angle;
	cosAng = cos(angRad);
	sinAng = sin(angRad);
	t = 1.0 - cosAng;

	Trans ( matrix1, -p1x, -p1y, -p1z);
	Trans ( matrix3, p1x, p1y, p1z);

	axisX = p2x - p1x;
	axisY = p2y - p1y;
	axisZ = p2z - p1z;

	// normalizar Axis
	length = sqrt ( axisX*axisX + axisY*axisY + axisZ*axisZ);
	axisX = axisX/length;
	axisY = axisY/length;
	axisZ = axisZ/length;

	matrix2->r1X = t*axisX*axisX + cosAng;
	matrix2->r2X = t*axisX*axisY - sinAng*axisZ;
	matrix2->r3X = t*axisX*axisZ + sinAng*axisY;

	matrix2->r1Y = t*axisY*axisX + sinAng*axisZ;
	matrix2->r2Y = t*axisY*axisY + cosAng;
	matrix2->r3Y = t*axisY*axisZ - sinAng*axisX;
	
	matrix2->r1Z = t*axisZ*axisX - sinAng*axisY;
	matrix2->r2Z = t*axisZ*axisY + sinAng*axisX;
	matrix2->r3Z = t*axisZ*axisZ + cosAng;

	ComponerTrfm3D( matrix2, matrix3 );
	ComponerTrfm3D( matrix1, matrix2 );
	// this = (m3 * m2) * m1

	DestroyTrfm3D(matrix2);
	DestroyTrfm3D(matrix3);

	return matrix1;
  }


void Transform3D( trfm3D *thisTrfm3D, float *xTr, float *yTr, float *zTr )
{
    float   tmpR1X, tmpR1Y, tmpR1Z;
    float   tmpR2X, tmpR2Y, tmpR2Z;
    float   tmpR3X, tmpR3Y, tmpR3Z;
    float   tmpTrX, tmpTrY, tmpTrZ;
    float   tmpX,   tmpY,   tmpZ;
    float   scale;

    tmpX = *xTr;
    tmpY = *yTr;
    tmpZ = *zTr;

    scale = thisTrfm3D->scl;
    tmpR1X = thisTrfm3D->r1X * scale;
    tmpR1Y = thisTrfm3D->r1Y * scale;
    tmpR1Z = thisTrfm3D->r1Z * scale;
    tmpR2X = thisTrfm3D->r2X * scale;
    tmpR2Y = thisTrfm3D->r2Y * scale;
    tmpR2Z = thisTrfm3D->r2Z * scale;
    tmpR3X = thisTrfm3D->r3X * scale;
    tmpR3Y = thisTrfm3D->r3Y * scale;
    tmpR3Z = thisTrfm3D->r3Z * scale;
    tmpTrX = thisTrfm3D->trX;
    tmpTrY = thisTrfm3D->trY;
    tmpTrZ = thisTrfm3D->trZ;

    *xTr = tmpX * tmpR1X + tmpY * tmpR2X + tmpZ * tmpR3X + tmpTrX;
    *yTr = tmpX * tmpR1Y + tmpY * tmpR2Y + tmpZ * tmpR3Y + tmpTrY;
    *zTr = tmpX * tmpR1Z + tmpY * tmpR2Z + tmpZ * tmpR3Z + tmpTrZ;
}
