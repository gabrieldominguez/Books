Frequently Asked Questions
These are all based on real e-mails that I receive week after week.

Q. Do you know anything about the ******** file format?
A. If you cannot find what you are looking for on the site then nobody has submitted any information on that format. Wotsit's Format does not have any 'secret' information.

Q. The information about ******** is incomplete, do you have any more information?
A. No, the only information I have is what is on the site.

Q. If I send you this file can you tell me what it is?
A. No, I am not an expert in most of the file formats here and do not have enough time to look into it. Wotsit's Format is run as a hobby in my free time, just keeping it up to date takes a lot of time.

Q. Can you tell me how to write a program to.....
A. NO!

Q. I need to convert xxxxx to yyyyy, can you help?
A. Again this is not the purpose of this site.

Q. Can I link to your site?
A. Most certainly, but please only link to the main page at http://www.wotsit.org

Q. What information will Wotsit's Format list?
A. The site is intended to be a comprehensive collection of data on as many file and data formats as possible. If you have any information that other programmers could make use of them please submit it to the site.

Q. What format should I submit information in?
A. Most of the information on the site is in plain ASCII text files. These are small size and can be used by all platforms. The next best format is as HTML web pages as these are also universal. Documents in other formats are always welcome though.

Q. I want to submit information about a format, what do I do?
A. You can either submit the file(s) to submit@wotsit.org for them to be included on Wotsit's Format. As space on the server and bandwidth are finite, fine sizes should be kept as small as possible. Alternatively if you maintain a live resource dedicated to a format, Wotsit's Format can include a link to your site, just let me know the address of the page.

Q. File xxxxx is in the wrong category in the index.
A. I am always willing to re-catagorise files on the site. The way the site engine works allows files to be in multiple categories and new categories can be created. Please let me know what you think needs changing.
