gluDeleteNurbsRenderer(3G)     OpenGL Reference	    gluDeleteNurbsRenderer(3G)



NAME
     gluDeleteNurbsRenderer - destroy a	NURBS object


C SPECIFICATION
     void gluDeleteNurbsRenderer( GLUnurbs* nurb )


PARAMETERS
     nurb  Specifies the NURBS object to be destroyed (created with
	   gluNewNurbsRenderer).


DESCRIPTION
     gluDeleteNurbsRenderer destroys the NURBS object and frees	any memory
     used by it.  Once gluDeleteNurbsRenderer has been called, nurb cannot be
     used again.
