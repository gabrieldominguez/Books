3. Mi primer ejemplo (E01)

Esta aplicación dibuja una línea en una ventana, creada para dibujar objetos OpenGL. Lo que se quiere mostrar en ella es como inicializar una ventana para poder utilizar los comandos de OpenGL. Para ello se utilizan las librerías GLUT (OpenGL Utilities Toolkit).

Funciones OpenGL principales utilizadas:

  • glutInitDisplayMode ( GLUT_RGB ) - Inicializa el modo de visualización. GLUT_RGB es una constante de OpenGL que indica que se van a utilizar colores RGB (por defecto sino se indica nada).

  • glutInitWindowSize ( WIDTH, HEIGHT ) - Indica el tamaño de la ventana que se va a crear para OpenGL.

  • glutInitWindowPosition ( 100, 100 ) - Posición del vértice superior izquierda donde se abrirá la ventana.

  • glutCreateWindow("E01: Mi primer ejemplo") - Crea la ventana con las propiedades definidas anteriormente.

  • glutDisplayFunc( display ) - Cuando por alguna causa se debe pintar la ventana de nuevo, por ejemplo al cambiarla de posición o de tamaño, el sistema llamara a la función "display". Esta función la creara el programador de la aplicación. En esta función hay que introducir el código necesario para que se dibuje la escena, se especifica mas adelante. · glutReshapeFunc( resize ) - Cuando la ventana cambia de tamaño el sistema llamara a la función "resize", creada por el programador. Se define mas adelante.

  • glutMainLoop() - Esta función detecta las acciones del usuario sobre el teclado ( u otro dispositivo). Cuando la acción afecta a la ventana creada por el programa, se encarga de llamar a las funciones creadas por el programador necesarias, según la acción, en este caso "display" o "resize".

  • void resize( int w, int h ) - Llamada cuando se modifica el tamaño de la ventana, y al crearse. La declaración no se puede modificar. Dentro se puede observar las siguientes funciones:

    • glClearColor( 0.0, 0.0, 0.0, 1.0 ) - Indica el color que se utilizara cuando se llama a la función glClear().

    • glViewport( 0, 0, w, h ) - Define la porción de ventana en la que se presentara el dibujo. En este caso utiliza toda la ventana.

    • glMatrixMode( GL_PROJECTION ) - Se estudia más adelante en otro ejemplo. · glLoadIdentity() - Se estudia mas adelante en otro ejemplo.

    • glOrtho( -50.0, 50.0, -50.0, 50.0, -50.0, 50.0 ) - Se estudia más adelante en otro ejemplo.

  • void display(void) - llamada cada vez que hay que pintar la ventana. La declaración no se puede modificar. Dentro de esta función estamos llamando a las siguientes funciones:

    • glClear( GL_COLOR_BUFFER_BIT ) - Limpia los buffers señalados. En este caso llena todos los pixels con el color de fondo, definido en glClearColor().

    • glColor3f( 1.0, 1.0, 1.0 ) - Selecciona el color con el que se pinta, hasta que se vuelva a llamar a esta función. Los parámetros indican el color RGB.

    • glBegin( GL_LINES ) - Indica que se comienza a definir una primitiva, en este caso una línea.

    • glVertex3f( -30.0f, -30.0f, 0.0f ) - Da las coordenadas de un vértice o punto.

    • glEnd() - Final del glBegin, aquí termina la definición.

    • glFlush() - Esta instrucción provoca la ejecución de cualquier comando OpenGL que aun no haya sido ejecutado. Internamente OpenGL procesa los comandos secuencialmente. Los comandos de OpenGL hacen cola, hasta que la aplicación procesa varias peticiones. [ Wrigth & Sweet, 1997 ] Pag. 75.

     

Código fuente

E01.c

// ejemplo que dibuja una simple linea en pantalla
#include < GL/glut.h > 
#define WIDTH 200 /* Ancho ventanas en pixels */ 
#define HEIGHT 200 /* Alto ventanas en pixels */ 
Display(void) {
		glClear( GL_COLOR_BUFFER_BIT ); 
		glColor3f( 0.0, 0.0, 0.0 ); 
		glBegin( GL_LINES ); 
		glVertex3f( -30.0f, -30.0f, 0.0f ); 
		glVertex3f( 30.0f, 30.0f, 0.0f ); 
		glEnd(); 
		glFlush(); 
} 

void Resize( int w, int h ) { 
		glClearColor( 1.0, 1.0, 1.0, 1.0 ); 
		glViewport( 0, 0, w, h ); 
		glMatrixMode( GL_PROJECTION ); 
		glLoadIdentity(); // creamos un volumen de visualizacion 
		glOrtho( -50.0, 50.0, -50.0, 50.0, -50.0, 50.0 ); 
		glMatrixMode( GL_MODELVIEW ); 
		glLoadIdentity();
}
 
int main(int argc, char** argv) { 
		glutInitDisplayMode ( GLUT_RGB ); 
		glutInitWindowSize ( WIDTH, HEIGHT ); 
		glutInitWindowPosition ( 100, 100 ); 
		glutCreateWindow("E01: Mi primer ejemplo"); 
		glutDisplayFunc( Display );
		glutReshapeFunc( Resize ); 
		glutMainLoop(); 
		return 0; 
}
