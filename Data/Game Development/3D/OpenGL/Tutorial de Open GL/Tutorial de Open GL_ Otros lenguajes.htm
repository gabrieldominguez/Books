12.- Otros lenguajes

OpenGL esta principalmente preparado para utilizarse con C. Lenguaje que se ha utilizado en este tutorial. Pero no por ello es el único lenguaje con el que se puede utilizar, y como muestra aquí se introducen algunos de ellos.

12.1.- C++ y Visual C++

Para poder utilizar OpenGL con C++ no es necesario nada aparte de las librerías, tal y como se utiliza con C. Viene bien recordar que en Internet se pueden encontrar otras librerías diferentes a las aquí mencionadas, que facilitan la programación. Entre éstas se encuentra la GLUI (GLUT User Interface). GLUI es una librería de Interface en C++ basada en la librería GLUT. Proporciona entre otras cosas controles como buttons, checkboxes, radio buttons, etc ... En el caso de Visual C++, es necesario además de las funciones de OpenGL otras funciones de Windows especificas para la unión entre OpenGL y el GDI.

12.2.- Visual Basic

OpenGL se puede utilizar con Visual Basic. El problema que tiene VB para utilizarlo, es la incompatibilidad en los tipos. Para solucionar el problema lo único que se necesita es una librería de tipos, que se puede encontrar gratuita en [Edx], que se llama "VBOpenGL.tlb". Sobre la librería mas utilizada en los tutoriales que se pueden encontrar en la red, y en este mismo, la GLUT 3.6, no es totalmente compatible con VB, así que en su lugar se puede utilizar la librería 'glxCtl', similar en estructura y uso a la GLUT, pero escrita en VB5. Esta librería es freeware, según explica en la pagina donde se puede conseguir [Edx].

12.3.- Delphi

Para interactuar OpenGL y Delphi, es necesario realizar algunos cambios, entre los que se encuentran el utilizar una unidad o modulo llamado "OpenGL.pas", para Delphi 2.4, que se puede encontrar en [Delphi-Jedi]. La unidad fue traducida de los ficheros de cabecera de C gl.h y glu.h, pero se ha extendido algo para facilitar el uso de OpenGL en sus programas. Estas extensiones abarcan rutinas para setup, un contexto de representación las activan y desactivan, para mantener un contexto específico según la extensión disponible de OpenGL. "OpenGL.pas" es freeware y se puede utilizar donde se desee. Entre los cambios realizados en la creación de OpenGL.pas está el de los nombres de los tipos, como por ejemplo de Glenum a TGLenum, para darle un estilo más parecido al de Delphi. Para mas información o conocimientos sobre como utilizar OpenGL con delphi se encuentra un tutorial en [Rincon 1999].

12.4.- Perl

Con la ultima versión de OpenGL ha salido a la vez el modulo de Perl OpenGL, de Stan Melax. Es la versión 0.4 del modulo, que proporciona acceso a la mayoría de las funcionalidades de OpenGL desde Perl, a una velocidad comparable a la que se consigue con C, pero con la comodidad que representa para los amantes del Perl. [Descartes 1998]. Para poder utilizar OpenGL con Perl es necesario el modulo antes indicado, que se puede encontrar en [CPAN 1999]. Hay que recordar que antes de utilizar el modulo se debe leer el fichero adjunto "readme".

12.5.- Ada

Todo lo necesario para poder utilizar OpenGL con Ada se encuentra en [Richards 1998]. Estos son paquetes traducidos de las librerías originales de OpenGL a Ada. Cabeceras y cuerpos, con lo cual la utilización de las librerías es similar a la de cualquier otro paquete de Ada que se implemente.

12.6.- Tcl/Tk

Para utilizar OpenGL con Tk o Tcl/Tk existe una librería o modulo, llamada Togl, que permite interactuar Tk y OpenGL. Togl crea una 'ventana' para Tk donde se puede renderizar en OpenGL. Togl esta basado en OGLTK, escrito por Benjamin Bederson de la Universidad de Nuevo Mejico. Togl permite crear y manejar una 'ventana' Tk/OpenGL especial para Tcl y renderizar en ella, como si fuera una aplicación de C. Togl es copyright de Brian Paul (brianp@elastic.avid.com) y Benjamin Bederson (bederson@cs.unm.edu). [Paul & Bederson 1997]

12.7.- Java

El propósito de GL4Java es la de usar Java como plataforma de programación independiente para aplicaciones OpenGL. El interfaz de OpenGL para trabajar con java lo comenzó Leo Chan [Chan 1996]. Implementó la librería con llamadas nativas de Java 1.0.2 y una ventana extra para renderizar OpenGL. GL4Java mapea el API de OpenGL a Java e implementa funciones de manejo de ventanas (nativas y de java) mientras usa las JNI (Java Native Interface). La librería JNI usa las librerías nativas de OpenGL del S.O. El Applet GL4Java se puede utilizar en navegadores como Netscape4.5 ó en aquellos que dispongan de Java2 Plug-In.
