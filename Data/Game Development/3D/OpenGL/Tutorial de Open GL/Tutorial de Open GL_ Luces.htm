9. Luces (E07)

Esta función introduce los conceptos de luminosidad, o luces.

Para ello lo que se hace es crear una escena en la cual se modifican los parámetros de las luces, así como su posición. Se dibuja una esfera amarilla en el punto donde se encuentra el foco de luz, para apreciar mejor la forma de acción.

También se introducen los conceptos de las cuadricas, que son operaciones definidas para Win32, para la realización de estructuras simples, cubos, cilindros y esferas. Estos objetos guardan información relacionada con el material de los objetos, siendo posible definir un tipo de material y utilizarlo por más de un objeto.

OpenGL maneja hasta ocho luces a la vez, definidas desde GL_LIGHT0 hasta GL_LIGHT7. Para que el efecto de las luces se note en los objetos hay que proporcionar a estos unas características de luminosidad y reflectancia. Esto es importante, ya que ahora un objeto no va a ser de color rojo, sino que va a ser de un material que refleja principalmente el color rojo.

Para asignar propiedades a los materiales se utilizan algunas de las funciones vistas en el ejemplo anterior, que se quedaron sin explicar:

  • glEnable (GL_COLOR_MATERIAL ) - Activa el seguimiento de color.

  • glColorMaterial (GL_FRONT,GL_DIFFUSE ) - Selecciona las propiedades de un material. Se pueden definir ciertas propiedades siguiendo el color especificado por glColor(). El primer parámetro indica la cara sobre la que tiene efecto, y el segundo especifica la propiedad del material que debe seguir el color actual. Puede tomar los valores GL_AMBIENT, GL_DIFFUSE, GL_SPECULAR y GL_AMBIENT_AND_DIFFUSE. Esta relacionada con:

  • glMaterial() - Se usa para seleccionar las propiedades reflectivas de los materiales de los polígonos. Se pueden seleccionar propiedades para la luz incidente(GL_AMBIENT ..), para aquellos materiales que producen su propia luz (GL_EMISION), producir reflejos mayores (GL_SHININESS) ...

Otras funciones relacionadas con las propiedades de los materiales son:

  • glGetMaterial() - Devuelve las propiedades seleccionadas del material actual. Para definir las luces se utilizan algunas de las funciones vistas en el ejemplo anterior, y que se quedaron sin explicar:

  • glEnable ( GL_LIGHTING ) - Activa las propiedades de luz.

  • glLightfv ( GL_LIGHT0, GL_ DIFFUSE, diffuseLight ) - Define los parámetros de una de las ocho fuentes de luz soportadas. Los parámetros que se pueden definir son: GL_AMBIENT que especifica las componentes ambiente de la luz; GL_DIFFUSE que especifica las componentes difusa de la luz; GL_SPECULAR que especifica las componentes especular de la luz; GL_POSITION especifica la posición de la luz, son cuatro componentes, los tres primeros especifican la posición, mientras que el cuarto si es uno indica que la luz esta situada en esa posición mientras que si es cero, que la luz es direccional y paralela al vector; ...

  • glEnable ( GL_LIGHT0 ) - Activa la luz especificada.

  • glPushAttrib(GL_LIGHTING_BIT) - Almacena las propiedades de la luz, para que no causen efecto.

  • glPopAttrib() - Restablece las propiedades de la luz. Otras instrucciones relacionadas con las luces son:

  • glGetLight() - Devuelve información sobre los ajustes de la fuente de luz indicada. El parámetro de retorno depende de propiedad solicitada. Ver [ Wrigth & Sweet, 1997 ] pagina 340.

  • glLightModel() - Define los parámetros del modelo de iluminación empleado por OpenGL.

En esta aplicación también se tratan las cuadricas que son parte de librería GLU32.LIB que soporta el dibujo de formas tridimensionales simples.

Las funciones empleadas en el ejemplo son:

  • GLUquadricObj - Tipo cuadrica. · gluNewQuadric() - Función que crea un nuevo objeto de estado cuadrico.

  • gluQuadricDrawStyle(quadObj,GLU_FILL) - Especifica el estilo con el que se dibujaran los objetos definidos por quadObj, que es un objeto cuadrico.

  • gluQuadricNormals(quadObj,GLU_SMOOTH) - Especifica la normal que se ha de calcular, en los vértices, o en el polígono.

  • gluQuadricOrientation(quadObj,GLU_OUTSIDE) - Especifica la orientación de las normales.

  • gluSphere(quadObj,2.0f, 25, 25) - Dibuja una esfera siguiendo las características del objeto cuadrico quadObj, definido anteriormente.

  • gluCylinder(quadObj,2.0f, 0.0f, 4.0f, 25, 25) - Dibuja un cilindro sin tapas siguiendo las características del objeto cuadrico quadObj, definido anteriormente.

  • gluDeleteQuadric(quadObj) - Elimina el objeto cuadrico especificado.

Otras funciones relacionadas con las cuadricas son:

  • gluQuadricCallback() - Define una llamada de rellamada cuadrica. En estos momentos la única disponible es GLU_ERROR que se invoca cuando se quiere producir un error.

  • gluQuadricTexture() - Activa o desactiva las coordenadas de textura para el mapeado de texturas sobre un objeto cuadrico.

void Resize( int w, int h )
{
	glClearColor(0.8f, 0.7f, 1.0, 1.0);

	glViewport( 0, 0, w, h );

	glMatrixMode( GL_PROJECTION );
	glLoadIdentity();

	gluPerspective(FEA_Camera->angle, w/h, FEA_Camera->front, 
FEA_Camera->back);

	glMatrixMode( GL_MODELVIEW );
	glLoadIdentity();

	glutPostRedisplay();

}

void Light ()
{	

	glDepthFunc( GL_LESS);
	glClearDepth(1.0);
	glEnable( GL_DEPTH_TEST );


	glCullFace (GL_BACK);
	glFrontFace (GL_CCW);
	glEnable( GL_CULL_FACE );

	// definimos las luces
	glEnable( GL_LIGHTING );


	glLightfv( GL_LIGHT0, GL_AMBIENT, FEA_AmbientLight );
	glLightfv( GL_LIGHT0, GL_DIFFUSE, FEA_DiffuseLight );
	glLightfv( GL_LIGHT0, GL_SPECULAR, FEA_SpecularLight );
	glLightfv( GL_LIGHT0, GL_POSITION, FEA_LightPos );
	glEnable( GL_LIGHT0 );


	glEnable (GL_COLOR_MATERIAL );

	glColorMaterial (GL_FRONT,GL_AMBIENT_AND_DIFFUSE );

	glMaterialfv (GL_FRONT, GL_SPECULAR, FEA_SpecularLight);
	glMateriali (GL_FRONT, GL_SHININESS, 128);
	
	glEnable(GL_NORMALIZE);

}

void DrawObj () 
{

	GLUquadricObj *quadObj;

	glColor3f ( 1.0f, 0.0f, 0.0f);
		// Setup Quadric Styles
		quadObj = gluNewQuadric();
		gluQuadricDrawStyle(quadObj,GLU_FILL); // GLU_LINE
		gluQuadricNormals(quadObj,GLU_SMOOTH); // One for each vertex
		gluQuadricOrientation(quadObj,GLU_OUTSIDE); // Normals point out

		glPushMatrix();
			glTranslatef(15.0f, 1.7f, 10.0f);
			gluSphere(quadObj,2.0f, 25, 25);
		glPopMatrix();
		

		// Draw the cone
		glPushMatrix();
			glTranslatef(10.0f, 0.0f, 15.0f);
			glRotatef(-90.0f, 1.0f, 0.0f, 0.0f);
			gluCylinder(quadObj,2.0f, 0.0f, 4.0f, 25, 25);
		glPopMatrix();
		gluDeleteQuadric(quadObj);
}



void DrawFloor()
{
	int x = 0;
	int z = 0;

	glPushMatrix();
	glColor3f ( 1.0f, 1.0f, 1.0f);
	for (z = 0; z <= 20; z++)
	{
		for (x = 0; x <= 20; x++)
		{
			
			glNormal3f( 0.0f, 1.0f, 0.0f );
			glBegin(GL_QUADS);
			glVertex3f( (float) x,   0.0f, (float) z+1);
			glVertex3f( (float) x+1, 0.0f, (float) z+1);
			glVertex3f( (float) x+1, 0.0f, (float) z);
			glVertex3f( (float) x,   0.0f, (float) z);
			glEnd();
		}
	}

	glPopMatrix();
}
