glDeleteTexturesEXT(3G)	       OpenGL Reference	       glDeleteTexturesEXT(3G)



NAME
     glDeleteTexturesEXT - delete named	textures


C SPECIFICATION
     void glDeleteTexturesEXT( GLsizei n,
			       const GLuint *textures )


PARAMETERS
     n	       The number of textures to be deleted.

     textures  An array	in which each element is the name of a texture to be
	       deleted.

DESCRIPTION
     glDeleteTexturesEXT deletes n textures named by the elements of the array
     textures.	After a	texture	is deleted, it has no contents or
     dimensionality, and its name is free for reuse (by	glGenTexturesEXT, for
     example).	If a texture that is currently bound is	deleted, the binding
     reverts to	zero (the default texture).

     glDeleteTexturesEXT silently ignores zeros	and names that do not
     correspond	to existing textures.

     glDeleteTexturesEXT is not	included in display lists.

NOTES
     glDeleteTexturesEXT is part of the	EXT_texture_object extension.  See
     glIntro for more information about	using extensions.

ERRORS
     GL_INVALID_VALUE is generated if n	is negative.

     GL_INVALID_OPERATION is generated if glDeleteTexturesEXT is executed
     between the execution of glBegin and the corresponding execution of
     glEnd.

ASSOCIATED GETS
     glIsTextureEXT
