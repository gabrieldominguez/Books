8. Sombreado (E06)

Esta función introduce los conceptos del sombreado.

Para ello el objeto que se dibuja en pantalla deja el aspecto esquelético que mostraba en los ejemplos anteriores y pasa a ser de aspecto sólido. También es necesario introducir el concepto de normales, tanto al polígono, como a los vértices.
Para que se vea más claro, en el ejemplo se introduce una luz difusa, blanca y fija (las luces se muestran en el ejemplo siguiente a éste).

El sombreado tiene dos formas, sombreado suave (smooth) y sombreado plano (flat). Para el sombreado plano, hay que indicar la normal al polígono, mientras que con el sombrado suave hay que indicar las normales a los vértices. Estas normales, se calculan, en el ejemplo, a la vez que se crea el objeto, es decir en la función LoadWaveFront().

También es necesario definir ciertos parámetros a la hora de dibujar, para que se puedan apreciar las diferencias entre los dos tipos de sombreado. Estas características están relacionadas con la manera de construir el objeto, y la forma de representarlo en pantalla. Así se introduce el buffer de profundidad, que permite que los polígonos más lejanos se oculten de los más cercanos, también la propiedad de ocultar caras, de tal forma que las caras no visibles no tengan que pintarse, ahorrando tiempo en cálculos que no se apreciarían. Estos parámetros se pueden modificar en el menú, así se puede comprobar los efectos sobre una misma figura.

Funciones añadidas en esta aplicación:

  • void Light () - Procedimiento en el cual se inicializan todos los elementos relacionados con las luces y los materiales. Es creado por el programador, y puede variar el nombre y los parámetros. No es propio de OpenGL. Dentro se puede observar las siguientes funciones:

    • glDepthFunc ( function_test ) - Selecciona la verificación de profundidad para la eliminación de caras ocultas. El argumento indica la función de comparación del buffer de profundidad que se usará.

    • GlClearDepth ( GLfloat ) - Valor con el que se borra el buffer de profundidad. Indica el valor inicial de referencia en Z. Por defecto OpenGL lo inicializa a 1.0, que representa la distancia máxima, si la ecuación elegida es GL_LESS. Sus valores van del 0.0 al 1.0.

    • glEnable ( GL_DEPTH_TEST ) - Activa la función que controla el buffer de profundidad..

    • glCullFace ( GL_BACK ) - Especifica si hay que eliminar de un polígono la cara frontal o la trasera. Su argumento puede valer GL_BACK o GL_FRONT.

    • glFrontFace ( GL_CCW ) - Especifica qué cara del polígono es la frontal, según el orden en que se definen los vértices. GL_CCW indica que están en sentido antihorario, mientras que GL_CW que están en sentido horario. Es necesario que todos los polígonos se definan en el mismo orden para evitar ocultar aquellos que no se desean.

    • glEnable ( GL_CULL_FACE ) - Activa la eliminación de las caras ocultas, según la opción definida en glCullFace(). Lo que hace es eliminar los cálculos, así como la iluminación, sombreado etc, de la cara seleccionada, con lo que se gana velocidad.

    • glEnable ( GL_LIGHTING ) - Se estudia más adelante en otro ejemplo.

    • glLightfv ( GL_LIGHT0, GL_ DIFFUSE, diffuseLight ) - Se estudia más adelante en otro ejemplo.

    • glLightfv ( GL_LIGHT0, GL_POSITION, lightPos ) - Se estudia más adelante en otro ejemplo.

    • glEnable ( GL_LIGHT0 ) - Se estudia más adelante en otro ejemplo.

    • glEnable (GL_COLOR_MATERIAL ) - Se estudia más adelante en otro ejemplo.

    • glColorMaterial (GL_FRONT,GL_DIFFUSE ) - Se estudia más adelante en otro ejemplo.

    • glEnable ( GL_NORMALIZE ) - Activa la conversión automática de las normales a normales unidad.

  • glNormal3f ( poly->xVNormal[i], poly->yVNormal[i], poly->yVNormal[i] ) - Define una normal a la superficie para el próximo vértice o grupo de vértices especificados. Se usa para los cálculos de sombreado e iluminación. La velocidad de generación se mejora especificando normales de longitud 1, para ello se puede activar GL_NORMALIZE ya vista.

  • glShadeModel ( GL_SMOOTH ) - Selecciona el tipo de sombreado que se va a realizar. El argumento puede tomar los valores GL_SMOOT, sombreado suave y GL_FLAT, sombreado plano.

  • glDisable ( GL_CULL_FACE ) - Desactiva la opción de eliminación de caras.

  • GlutChangeToMenuEntry (4, "Disable Cull Face", 3) - Modifica el nombre del ítem indicado en el submenu actual. Los ítems se numeran de 1 a glutGet( GLUT_MENU_NUM_ITEMS ).

  • GLUT_DEPTH - Se añade el parámetro que activa el buffer de profundidad, al llamar a la función glutInitDisplayMode.

  • GL_DEPTH_BUFFER_BIT - Se añade el parámetro que indica borrar el buffer de profundidad en glClear.

Otras funciones relacionadas con el sombreado o con las propiedades del material de los polígonos son:

  • glPolygonMode ( cara, modo ) - Selecciona el modo en que se generan los polígonos. Por defecto los polígonos se dibujan en modo sólido por las dos caras. El primer argumento señala a que cara se va a aplicar, y el segundo especifica el modo de dibujo, FILL ( sólido), LINE (perfiles) o POINT (solo los vértices).

void Display( void )
{
    polygon *poly;
	int      j = 1;
	int      i;
	int      numPol;
    GLfloat  glMatrix[16];
	GLint    viewport[4];

	glGetIntegerv( GL_VIEWPORT, viewport ); 

	glMatrixMode( GL_PROJECTION );
	glLoadIdentity();

	gluPerspective(FEA_Camera->angle, viewport[2]/viewport[3],
		           FEA_Camera->front, FEA_Camera->back);  

	glMatrixMode( GL_MODELVIEW );
	glLoadIdentity();

	glPushMatrix(); 

	SetGlMatrix( FEA_Transform, glMatrix );
	glLoadMatrixf( glMatrix );

	gluLookAt( 
FEA_Camera->eyeX,    FEA_Camera->eyeY,    FEA_Camera->eyeZ,
	FEA_Camera->centerX, FEA_Camera->centerY, FEA_Camera->centerZ,
	FEA_Camera->upX,     FEA_Camera->upY,     FEA_Camera->upZ); 


	glColor3f( 0.0, 1.0, 0.0 );


	if ( FEA_Shade == FLAT ) glShadeModel ( GL_FLAT );  // new
	else glShadeModel ( GL_SMOOTH );  // new
	
	glClear( GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT );	

	
    /***********************/

	poly = StartLoop( FEA_ListPol );

	numPol = ElementsInList( FEA_ListPol );

	while ( j <= numPol )
	{ 
		
		if (poly->numVert == 2) 
		{ 
			glColor3f( 1.0f, 0.0f, 0.0f);
			glBegin( GL_LINES );
				glVertex3f( poly->xCoor[0], poly->yCoor[0], 
poly->zCoor[0] );
glVertex3f( poly->xCoor[1], poly->yCoor[1], 
poly->zCoor[1] );
			glEnd();
		}
		else
		{
			glColor3f( 0.0f, 1.0f, 0.0f);
			glBegin( GL_POLYGON );
			
			if ( FEA_Shade == FLAT ) 
			{
				glNormal3f( poly->normalVector->xnv, 
				        	poly->normalVector->ynv, 
						poly->normalVector->znv );
			}
			for ( i=0; i < poly->numVert; i++ )
			{
				if ( FEA_Shade == SMOOTH ) 
				{
					glNormal3f( poly->xVNormal[i], 
poly->yVNormal[i], 
poly->yVNormal[i] ); 
				}
				glVertex3f( poly->xCoor[i], poly->yCoor[i], 
poly->zCoor[i] );
			}
			glEnd();

		}
		j++;
		poly=GetNext( FEA_ListPol );
	}

	glPopMatrix();
	glutSwapBuffers();
}


void CalculateMaxMin ( )  
{

    polygon *poly;
	int      j = 1;
	int      i;
	int      numPol;

	poly = StartLoop( FEA_ListPol );

	numPol = ElementsInList( FEA_ListPol );

	FEA_maxX    = poly->xCoor[1];
FEA_minX    = poly->xCoor[1];
    	FEA_maxY    = poly->yCoor[1];
    	FEA_minY    = poly->yCoor[1];
    	FEA_maxZ    = poly->zCoor[1];
    	FEA_minZ    = poly->zCoor[1];

	while ( j <= numPol )
	{ 
		for ( i=0; i < poly->numVert; i++ )
		{
			if ( FEA_maxX < poly->xCoor[i] ) 
FEA_maxX = poly->xCoor[i];
			if ( FEA_minX > poly->xCoor[i] ) 
FEA_minX = poly->xCoor[i];
			if ( FEA_maxY < poly->yCoor[i] ) 
FEA_maxY = poly->yCoor[i];
			if ( FEA_minY > poly->yCoor[i] ) 
FEA_minY = poly->yCoor[i];
			if ( FEA_maxZ < poly->zCoor[i] ) 
FEA_maxZ = poly->zCoor[i];
			if ( FEA_minZ > poly->zCoor[i] ) 
FEA_minZ = poly->zCoor[i];
		}
		j++;
		poly=GetNext( FEA_ListPol );
	}
}



void Resize( int w, int h )
{
	glClearColor(1.0, 1.0, 1.0, 1.0);

	glViewport( 0, 0, w, h );

	glMatrixMode( GL_PROJECTION );
	glLoadIdentity();

gluPerspective(FEA_Camera->angle, w/h, FEA_Camera->front, 
FEA_Camera->back);

	glMatrixMode( GL_MODELVIEW );
	glLoadIdentity();

	glutPostRedisplay();

}

void Light ()   // new
{


	GLfloat diffuseLight[] = { 0.8f, 0.8f, 0.8f, 1.0f };
	GLfloat lightPos[]     = { 100.0f, 100.0f, 100.0f, 1.0f };

	glDepthFunc( GL_GREATER );  
// utilizada por el buffer de profundidad 
	glClearDepth(0.0);
	glEnable( GL_DEPTH_TEST );


	glCullFace (GL_BACK);
	glFrontFace (GL_CCW);
	glEnable( GL_CULL_FACE );

	// definimos las luces

	glEnable( GL_LIGHTING );

	glLightfv( GL_LIGHT0, GL_DIFFUSE, diffuseLight );
	glLightfv( GL_LIGHT0, GL_POSITION, lightPos );
	glEnable( GL_LIGHT0 );

	glEnable (GL_COLOR_MATERIAL );

	glColorMaterial (GL_FRONT,GL_DIFFUSE );
	
	glEnable(GL_NORMALIZE);


}

static void SpecialKey(int k, int x, int y) 
{
	switch(k) 
	{
	case GLUT_KEY_UP:
		{
		if (FEA_Action == CAM_MERI_PARAL ) 
CamMeridiam ( FEA_Camera, 1.0 );
		else if (FEA_Action == CAM_TILT_ZOOM ) 
CamZoom ( FEA_Camera, -1.0 );
		}
		break;
	case GLUT_KEY_DOWN:
		{
		if (FEA_Action == CAM_MERI_PARAL ) 
CamMeridiam ( FEA_Camera, -1.0 );
		else if (FEA_Action == CAM_TILT_ZOOM ) 
CamZoom ( FEA_Camera, 1.0 );
		}
		break;
	case GLUT_KEY_RIGHT:
		{
		if (FEA_Action == CAM_MERI_PARAL ) 
CamParalell ( FEA_Camera, 1.0 );
		else if (FEA_Action == CAM_TILT_ZOOM ) 
CamTilt ( FEA_Camera, 1.0 );
		}
		break;
	case GLUT_KEY_LEFT:
		{
		if (FEA_Action == CAM_MERI_PARAL ) 
CamParalell ( FEA_Camera, -1.0 );
		else if (FEA_Action == CAM_TILT_ZOOM ) 
CamTilt ( FEA_Camera, -1.0 );
		}
		break;
	case GLUT_KEY_F1:
		FEA_Action = CAM_MERI_PARAL;
		break;
	case GLUT_KEY_F2:
		FEA_Action = CAM_TILT_ZOOM;
		break;
	case GLUT_KEY_F3:
		CamReset( FEA_Camera );
		break;
	default:
		break;
	}
	glutPostRedisplay();
}

#include < stdlib.h >
#include < math.h >

void DestroyUnitVector( unitVector *thisVector )
{
    free( thisVector );
}

unitVector *CreateUnitVector( float x, float y, float z)
{
    double       modulo;
    unitVector  *newUnitVector;

    newUnitVector = (unitVector *) malloc( sizeof(unitVector) * 1 );

    modulo = x*x + y*y + z*z;
    if( modulo > MIN_FLOAT ) 
        modulo = 1.0 / sqrt( modulo );
    else
        modulo = 1.0;

    newUnitVector->xnv = x * (float) modulo;
    newUnitVector->ynv = y * (float) modulo;
    newUnitVector->znv = z * (float) modulo;
    return newUnitVector;
}

float Escalar( unitVector *thisVector, unitVector *two )
{
    float producto;

    producto = thisVector->xnv * two->xnv + 
               thisVector->ynv * two->ynv + 
               thisVector->znv * two->znv;

    return producto;
}

void DestroyPolygon( polygon *thisPolygon )
{
    free( thisPolygon->xCoor );
    free( thisPolygon->yCoor );
    free( thisPolygon->zCoor );
    if( thisPolygon->xVNormal ) {
        free( thisPolygon->xVNormal );
        free( thisPolygon->yVNormal );
        free( thisPolygon->zVNormal );
 
    }
    DestroyUnitVector( thisPolygon->normalVector );
    free( thisPolygon );
}

polygon *CreatePolygon( int numVert, float *x, float *y, float *z )
{
    polygon  *newPolygon;

    newPolygon = (polygon *) malloc( sizeof(polygon) * 1 );
    newPolygon->numVert   = numVert;
    newPolygon->xCoor     = x;
    newPolygon->yCoor     = y;
    newPolygon->zCoor     = z;
    newPolygon->xVNormal  = NULL;
    newPolygon->yVNormal  = NULL;
    newPolygon->zVNormal  = NULL;

    SetPolygonNormal( newPolygon );

    return newPolygon;
}

polygon *CopyPolygon( polygon *thisPolygon, int order )
{
    polygon  *newPolygon;
    float    *xx,  *yy,  *zz;
    int       i;
    int       nv;

    nv = thisPolygon->numVert;
    xx = (float *) malloc( sizeof( float ) * nv+1 );
    yy = (float *) malloc( sizeof( float ) * nv+1 );
    zz = (float *) malloc( sizeof( float ) * nv+1 );

    if( order ) {
        for ( i=0; i < nv+1; i++ ) {
            xx[i] = thisPolygon-> xCoor[i];
            yy[i] = thisPolygon->yCoor[i];
            zz[i] = thisPolygon->zCoor[i];
        }
    }
    else {
        for ( i=0; i < nv+1; i++ ) {
            xx[i] = thisPolygon-> xCoor[nv-i];
            yy[i] = thisPolygon->yCoor[nv-i];
            zz[i] = thisPolygon->zCoor[nv-i];
        }
    }

    newPolygon = CreatePolygon( nv, xx, yy, zz );

    return newPolygon;
}

void AddVertsNormals( polygon *thisPolygon, float *x, float *y, float *z )
{
    int  nn;

    if( thisPolygon->xVNormal ) {
        free( thisPolygon->xVNormal );
        free( thisPolygon->yVNormal );
        free( thisPolygon->zVNormal );
    }
    else {
        nn = thisPolygon->numVert;
    }
    thisPolygon->xVNormal = x;
    thisPolygon->yVNormal = y;
    thisPolygon->zVNormal = z;
}

void SetPolygonNormal( polygon *thisPolygon )
{
    int         nv;
    float      *xp, *yp, *zp;
    float       A,   B,   C;
 
    A = B = C = 0;

    nv = thisPolygon->numVert;
    xp = thisPolygon->xCoor;
    yp = thisPolygon->yCoor;
    zp = thisPolygon->zCoor;

	A = yp[1]*(zp[2]-zp[3]) + yp[2]*(zp[3]-zp[1]) + 
yp[3]*(zp[1]-zp[2]);
	B = zp[1]*(xp[2]-xp[3]) + zp[2]*(xp[3]-xp[1]) + 
zp[3]*(xp[1]-xp[2]);
	C = xp[1]*(yp[2]-yp[3]) + xp[2]*(yp[3]-yp[1]) + 
xp[3]*(yp[1]-yp[2]);

    thisPolygon->normalVector = CreateUnitVector( A, B, C );
}
